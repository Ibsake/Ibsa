# AgriBridge - Digital Market App
Appiin kun oomishtoota baadiyyaa fi fedhii magala keessa jiru walitti hidhuuf kan qophaa'oodha.

## Akkaataa Appichi Itti Jalqabu (Setup)
1. **Koodii Buufachuu:** GitHub irraa ZIP buufadhu ykn `git clone` godhi.
2. **Node.js Fe'uu:** Kompiitara keerratti Node.js jiraachuu qaba.
3. **Dependencies:** Terminal irratti `npm install` barreessi.
4. **API Key:** Failii `.env.local` uumuun `GEMINI_API_KEY=keeti` galchi.
5. **Jalqabsiisuu:** Terminal irratti `npm run dev` barreessi.
